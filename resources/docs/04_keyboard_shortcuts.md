# Keyboard Shortcuts Guide

## 1. Introduction: Keyboard-Driven Workflow

Prism is designed for developers who value keyboard efficiency. Every major action—from launching the overlay, toggling reasoning modes, initiating screen captures, opening model selectors, to voice dictation—can be controlled via configurable system and app hotkeys.

---

## 2. Global OS Shortcuts

Global shortcuts register at the operating system level and function even when Prism is minimized or in the background. They are fully customizable in System Settings.

| Hotkey Parameter | Default Hotkey | Action Description |
| --- | --- | --- |
| `launcherShortcut` | `CommandOrControl+Space` | Toggle the Quick Launcher overlay open/closed |
| `screenshotShortcut` | `Ctrl+Alt+Space` | **Screenshot & Ask:** Captures full desktop screen, opens launcher overlay, and attaches image to prompt |
| `newChatShortcut` | `CommandOrControl+N` | Open a new chat session in the main window |
| `dictationShortcut` | `CommandOrControl+D` | Start/stop microphone audio dictation |
| `webSearchShortcut` | `CommandOrControl+S` | Toggle active Web Search Mode |
| `youtubeModeShortcut` | `CommandOrControl+Y` | Toggle YouTube Mode |
| `modelSelectionShortcut` | `CommandOrControl+M` | Open inline model selector in Quick Launcher |

## 3. Main Chat Workspace Shortcuts

| Hotkey | Context | Action |
| --- | --- | --- |
| `Enter` | Prompt InputBar | Send prompt message |
| `Shift+Enter` | Prompt InputBar | Insert newline character |
| `Ctrl+T` / `Cmd+T` | Prompt InputBar | Toggle Reasoning / Thinking mode on/off |
| `Ctrl+S` / `Cmd+S` | Prompt InputBar | Toggle Web Search mode on/off |
| `Ctrl+Y` / `Cmd+Y` | Prompt InputBar | Toggle YouTube mode on/off |
| `Ctrl+D` / `Cmd+D` | Prompt InputBar | Toggle microphone voice dictation |
| `Ctrl+N` / `Cmd+N` | Anywhere | Start new conversation session |
| `Escape` | Fullscreen Input | Exit fullscreen prompt mode |

---

## 4. Quick Launcher Overlay Shortcuts

| Hotkey | Launcher Component | Action |
| --- | --- | --- |
| `Escape` | Quick Launcher Window | Close launcher overlay immediately |
| `↑` / `↓` | Suggestion List | Navigate through app search results, file matches, math results, or models |
| `Enter` | Search Bar / Selected Item | Execute selected app/file or submit AI query |
| `Ctrl+M` / `Cmd+M` | Quick Launcher | Open inline model selector dropdown |
| `Ctrl+T` / `Cmd+T` | Quick Launcher | Toggle Think / Reasoning mode for launcher prompt |
| `Ctrl+S` / `Cmd+S` | Quick Launcher | Toggle Web Search mode for launcher prompt |
| `Ctrl+Y` / `Cmd+Y` | Quick Launcher | Toggle YouTube mode for launcher prompt |
| `Ctrl+D` / `Cmd+D` | Quick Launcher | Toggle Voice Dictation in launcher |
